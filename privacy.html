개인정보처리방침 / Privacy Policy

최종 수정 / Last updated: 2026-11-22

누가 쓰나 / Who uses it

Hermes Assistant는 개발자 본인 한 명만 쓰는 개인용 앱입니다. 다른 사람의 Google 계정 데이터에 접근하지 않습니다.

Hermes Assistant is used only by its developer. It does not access anyone else's Google account data.

접근하는 데이터 / Data accessed

Google Calendar API의 calendar.events 범위로 개발자 본인 캘린더의 일정을 읽고, 본인이 승인한 일정을 만들거나 고칩니다.

Using the calendar.events scope, the app reads events from the developer's own calendars and creates or updates events the developer approves.

저장과 공유 / Storage and sharing

  • OAuth 토큰과 일정 데이터는 개발자 소유의 서버에만 저장합니다. / OAuth tokens and calendar data are stored only on a server the developer owns.
  • 일정 계획을 돕기 위해 일정 내용이 개발자가 이용하는 AI 모델 서비스로 전송될 수 있습니다. / To help plan schedules, event content may be sent to the AI model services the developer uses.
  • 데이터를 판매하거나 광고에 쓰지 않으며, 그 밖의 제3자와 공유하지 않습니다. / Data is never sold, used for advertising, or shared with other third parties.

Google API 데이터 사용 / Google API data use

Google API에서 받은 정보의 사용과 전송은 Limited Use 요건을 포함한 Google API Services User Data Policy를 따릅니다.

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

삭제 / Deletion

Google 계정의 서드파티 액세스에서 권한을 취소하면 앱은 더 이상 접근할 수 없습니다. / Revoking access in Google Account third-party access settings stops all access.
